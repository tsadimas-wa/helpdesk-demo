# Definition of Done — v1 (Sprint 1)

| Κριτήριο | Από πού |
|---|---|
| ☐ Merge στο `main` μέσω pull request, μετά από review από άλλο μέλος | Πρακτική ομάδας |
| ☐ Κάθε acceptance criterion της story έχει αυτοματοποιημένο test που περνά | Ενότητα 8 |
| ☐ Κάλυψη νέου κώδικα ≥ 80% | NFR-15 |
| ☐ Το CI pipeline είναι πράσινο (build, tests, έλεγχοι ασφαλείας) | NFR-18 |
| ☐ Tests εξουσιοδότησης για κάθε νέο endpoint: πελάτης δεν βλέπει άλλον οργανισμό | NFR-09 |
| ☐ Νέες οθόνες: ελληνικά και αγγλικά· αυτόματος έλεγχος προσβασιμότητας χωρίς σφάλματα | C-04 · NFR-13 |
| ☐ Commit και PR αναφέρουν τους κωδικούς (FR/BR) και το issue (`Refs #N`) | §11.3 (ιχνηλασιμότητα) |
| ☐ Ο PO είδε τη story να λειτουργεί και τη δέχτηκε· μόνο αυτός κλείνει το issue | Πρακτική ομάδας |

**Θα προστεθούν αργότερα:** «η OpenAPI προδιαγραφή ενημερώθηκε» (Ενότητα 7) · «εγκαθίσταται αυτόματα στο staging» (Ενότητα 9).

# Definition of Ready

Μια story μπαίνει σε sprint μόνο αν:
- ☐ έχει ≥ 2 acceptance criteria, εγκεκριμένα από τον PO
- ☐ έχει εκτιμηθεί από την ομάδα
- ☐ δεν έχει ανοιχτή εξάρτηση εκτός ομάδας — ή η εξάρτηση είναι γραμμένη και η story δεν είναι στο Sprint Goal
- ☐ χωράει σε ένα sprint (≤ 8 πόντοι)
